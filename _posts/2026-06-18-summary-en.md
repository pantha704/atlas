The Internet Engineering Task Force (IETF) introduces a new HTTP query method (RFC 10008), which replaces the previously considered GET request with a body. This new method is significant because it provides a way to process request bodies in a safe and idempotent manner, addressing historical interoperability issues and strict compliance with HTTP core architectural definitions. The QUERY method is designed to be idempotent and safe, allowing request bodies to be processed without affecting the server's state. It also introduces a new Accept-Query field for registering query parameters.

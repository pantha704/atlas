## [RFC 10008: HTTP 查询方法的新规范](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

互联网工程任务组(IETF)推出了一个新的 HTTP 查询方法(RFC 10008)，该方法取代了之前被考虑的带有请求体的 GET 请求。 这个新方法很重要，因为它提供了一种在安全和幂等的方式处理请求体的方法，从而解决了历史上存在的互操作性问题和 HTTP 核心架构定义的严格遵守问题。 QUERY 方法设计为幂等和安全，允许请求体在不影响服务器状态的情况下被处理。它还引入了一个新的 Accept-Query 字段用于注册查询参数。

hackernews · schappim · Jun 17, 10:51 · [社区讨论](https://news.ycombinator.com/item?id=48568502)

**背景**: IETF 是一个负责互联网协议套件(TCP/IP)技术标准的标准组织。新 QUERY 方法是 HTTP 协议的一部分，用于在网络上传输数据。该方法旨在解决历史上存在的互操作性问题和 HTTP 核心架构定义的严格遵守问题。
